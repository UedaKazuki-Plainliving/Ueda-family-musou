# 上田家無双 〜ディスカバリー〜

「大乱闘上田家ファミリー」に続く、上田家ファミリーシリーズ第2弾。
three.js（同梱の `three-bundle.js`）で動く **3D一騎当千アクション × 箱庭探索** ゲームです。
**遊ぶ → https://uedakazuki-plainliving.github.io/Ueda-family-musou/**

ブラウザで `musou.html` を開くだけで遊べます（外部CDN・外部通信なし、PC / スマホ / ゲームパッド対応）。

- **三國無双っぽさ** … 数十体の雑兵をまとめてなぎ払う通常攻撃6段＋チャージ攻撃 C1〜C6、無双乱舞、拠点制圧 → 兵長 → 総大将
- **カービィ ディスカバリーっぽさ** … パステルな3D箱庭、多段ジャンプ・ホバリングで登る探索タワー、迷子のひよこ救出とスター集め、コピー玉（ファイア／アイス／サンダー）

## あそびかた

| 操作 | キーボード | ゲームパッド | スマホ |
|---|---|---|---|
| 移動 | WASD / 矢印 | 左スティック | 画面左をドラッグ |
| カメラ | マウスドラッグ・Q/E・ホイール、R でリセット | 右スティック、L3/R3 でリセット | 画面右をドラッグ |
| 通常攻撃 | J / Z | X（□） | 攻 |
| チャージ攻撃 | K / X | Y（△） | チャージ |
| ジャンプ | Space | A（×） | ジャンプ |
| 回避 | Shift / C | B（○）・トリガー | 回避 |
| 無双乱舞 | L / V | LB / RB | 無双 |
| ポーズ | Esc | START | ❚❚ |

- 通常攻撃（□）を n 回当ててからチャージ（△）で C(n+1) に派生。画面下の **コンボルート表示**（`●●○ → △ C3 回転斬り`）が次に出る技、発動時は技名がポップします。ポーズ画面にキャラ別の技表。
  C1 打ち上げ / C2 突進連撃 / C3 回転斬り / **C4 キャラ固有の必殺技** / C5 大地割り / C6 大地割り・極
- 回避中に□で **ダッシュ攻撃**、空中□で空中コンボ、空中△で急降下。
- 雑兵は1〜2発で吹き飛び、勢いよく飛んだ敵が周りを巻き込む **ふっとばし連鎖**。

### ステージごとのミッション

| ステージ | 流れ |
|---|---|
| 1 はじまりの庭 | 拠点制圧(2) → **防衛戦：上田家の洗濯物を45秒守れ** → 全拠点制圧 → ボス |
| 2 ほこりの廃モール | 拠点制圧(2) → **補給部隊追撃：逃げる荷車4台を壊せ** → 全拠点制圧 → ボス |
| 3 ヨゴレ城 | **城門突破** → 全拠点制圧 → **撃破チャレンジ：60秒で70人** → ボス |

成功するとごほうびアイテム＋スコアボーナス。拠点制圧中はランダムに **イベント** が発生：
金ホコリン（逃げる前に倒すとお宝）／フィーバータイム（敵増量・無双ゲージ2倍）／伏兵（包囲される）／巨大兵長ドッスン。

### ボス

どのボスも攻撃を当て続けると **ブレイク**（青ゲージ）して3秒間ダウン＆被ダメ1.6倍。HP半分で第2形態。

- **ホコリン大将** … ごろごろ転がり突進・手下召喚、第2形態で **分裂**（子ホコリン2体）
- **ソウジキ魔人** … **吸い込み**（回避で逃げる。雑兵も吸い込む）・ほこり竜巻、第2形態で吸引力アップ
- **ヨゴレキング** … **隕石落とし**（赤い予兆円）・**衝撃波リング**（ジャンプでかわす）、第2形態で激怒

### アイテム

おにぎり・肉まん（回復）、元気ドリンク（無双ゲージ）、コピー玉（属性）、スター、そして木箱やイベントから出るパワーアイテム：
**🍄 巨大化**（範囲・威力アップ、ひるまない）／**👟 スピード**／**🌟 無敵**（体当たりで蹴散らす）／**💣 爆弾**（周囲を大爆発）

「大乱闘上田家ファミリー（Ueda-family-battle / smash3d）」の家族5人を移植。配色・体格・髪型と、必殺技／超必殺技をチャージ4／無双乱舞に割り当てています。

| 🧑 ゆうり | 黄金の蹴り | ドロップキック（アーマー突進） | ゴールデンフェニックス | 攻撃中アーマー |
| 👧 そよ | リレーのバトン | 陸上こうげき（貫通3連弾） | 100m居合い切り | 最速移動・最長リーチ |

## ステージ

1. **はじまりの庭** — 上田家の庭。ボス：ホコリン大将
2. **ほこりの廃モール** — 夕暮れのモール跡。ボス：ソウジキ魔人
3. **ヨゴレ城** — 溶岩の城。ボス：ヨゴレキング

難易度（やさしい／ふつう／むずかしい）と画質（軽量／高／最高）は「せってい」から。ベストランクは端末に保存されます。
