# 上田家無双 〜ディスカバリー〜

「大乱闘上田家ファミリー」に続く、上田家ファミリーシリーズ第2弾。
three.js（同梱の `three-bundle.js`）で動く **3D一騎当千アクション × 箱庭探索** ゲームです。
**遊ぶ → https://uedakazuki-plainliving.github.io/Ueda-family-musou/**

ブラウザで `musou.html` を開くだけで遊べます（外部CDN・外部通信なし、PC / スマホ / ゲームパッド対応）。

- **三國無双っぽさ** … 数十体の雑兵をまとめてなぎ払う通常攻撃6段＋チャージ攻撃 C1〜C6、無双乱舞、拠点制圧 → 兵長 → 総大将
- **カービィ ディスカバリーっぽさ** … パステルな3D箱庭、多段ジャンプ・ホバリングで登る探索タワー、迷子のひよこ救出とスター集め、コピー玉（ファイア／アイス／サンダー）

## あそびかた

| 操作 | キーボード | ゲームパッド | スマホ |
|---|---|---|---|
| 移動 | WASD / 矢印 | 左スティック | 画面左をドラッグ |
| カメラ | マウスドラッグ・Q/E・ホイール、R でリセット | 右スティック、L3/R3 でリセット | 画面右をドラッグ |
| 通常攻撃 | J / Z | X（□） | 攻 |
| チャージ攻撃 | K / X | Y（△） | チャージ |
| ジャンプ | Space | A（×） | ジャンプ |
| 回避 | Shift / C | B（○）・トリガー | 回避 |
| 無双乱舞 | L / V | LB / RB | 無双 |
| ポーズ | Esc | START | ❚❚ |

- 敵の **拠点**（赤い円）で雑兵を倒すと拠点ゲージが減り、0 になると **拠点兵長** が出現。兵長を倒すと制圧（青）。
- 全拠点を制圧すると本陣に **総大将（ボス）** が出現。倒せばステージクリア。
- 通常攻撃を n 回当ててからチャージ攻撃を押すと C(n+1) に派生：
  C1 打ち上げ / C2 突進連撃 / C3 回転斬り / C4 キャラ別の必殺技 / C5 大地割り / C6 大地割り＋追撃
- 空中で攻撃 → 空中コンボ、空中でチャージ → 急降下衝撃波。
- 兵長が落とす **コピー玉** で25秒間、攻撃に属性（🔥燃焼 / ❄️凍結 / ⚡連鎖）が付く。
- 高い **探索タワー** の頂上に迷子のひよこ🐤。スター⭐や木箱（回復・無双ゲージ）も探そう。

## ステージ

1. **はじまりの庭** — 上田家の庭。ボス：ホコリン大将
2. **ほこりの廃モール** — 夕暮れのモール跡。ボス：ソウジキ魔人
3. **ヨゴレ城** — 溶岩の城。ボス：ヨゴレキング

難易度（やさしい／ふつう／むずかしい）と画質（軽量／高／最高）は「せってい」から。ベストランクは端末に保存されます。

## ファイル構成

```
index.html        musou.html へのリダイレクト（Pages のトップ）
musou.html        ゲーム本体（HTML/CSS/JS 1ファイル）
three-bundle.js   three.js r160 + addons 同梱（MIT License、大乱闘上田家ファミリーと共通）
test/smoke.mjs    Playwright スモークテスト（全ステージ×全キャラ起動・制圧→ボス撃破・タワー登頂）
```
